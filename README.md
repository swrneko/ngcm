# Glyph Charging Meter

Приложение для телефонов Nothing: во время зарядки показывает уровень заряда на Glyph-интерфейсе и проигрывает анимацию при подключении питания.

## Зачем это нужно

На Phone (3a) и Phone (3a) Pro встроенного индикатора заряда (Charging meter) нет: Nothing не перенесла эту функцию с Phone (1) и (2). Приложение возвращает её.

## Чем отличается от аналогов

Штатный `displayProgress` заполняет шкалу шагами по сегменту: на длинной зоне это 20 ступеней, то есть 5% заряда на ступень, и шкала заметно дёргается. Здесь яркость задаётся для каждого сегмента отдельно: целые сегменты горят на полной яркости, а следующий светится частично, пропорционально дробному остатку. Например, 63% на зоне из 20 сегментов это 12 сегментов на полной яркости и 13-й на 60%. Дополнительно шкала плавно переходит к новому значению при изменении заряда. Если недокументированная перегрузка SDK исчезнет в обновлении, приложение само перейдёт на ступенчатый режим и сообщит об этом.

Режимы индикатора: постоянный (шкала горит всю зарядку) и по событию (анимация при подключении, затем шкала держится заданное время и гаснет). В приложении есть превью пресетов, настройки яркости и длительности показа.

## Поддерживаемые устройства

| Устройство | Статус |
|---|---|
| Nothing Phone (3a), Phone (3a) Pro | Целевые устройства, раскладка добавлена. Проверка на железе ещё не проводилась |
| Остальные модели Nothing | Не поддерживаются сейчас; архитектура допускает добавление одной записью в таблицу раскладок |

Работа на живом телефоне пока не подтверждена: проект проверен только автоматическими тестами. Поведение SDK на Nothing OS 3.x без debug-режима и точная семантика отдельных вызовов подлежат проверке на устройстве.

## Установка

Скачайте APK из раздела releases и установите его.

**Nothing OS 4.0 и новее (Android 16).** Ничего настраивать не нужно: ограничение на доступ к Glyph снято.

**Более старые версии.** Нужен включённый Glyph Debug Mode, который система сбрасывает каждые 48 часов. Чтобы приложение включало его само, один раз выдайте ему разрешение командой с компьютера (телефон подключён по USB, включена отладка по USB):

```bash
adb shell pm grant com.swrneko.glyphmeter android.permission.WRITE_SECURE_SETTINGS
```

После этого приложение включает отладочный режим само и навсегда, к компьютеру возвращаться не нужно. Эту же команду показывает экран онбординга.

**Альтернатива без компьютера: Shizuku.** Shizuku запускается один раз через беспроводную отладку прямо на телефоне, и приложение записывает флаг через него. Минус: после перезагрузки телефона Shizuku нужно запускать заново.

## Сборка из исходников

Нужны JDK 17 и Android SDK (путь к нему в `local.properties`).

```bash
./gradlew assembleDebug    # APK: app/build/outputs/apk/debug
./gradlew test             # юнит-тесты
```

Glyph SDK лежит в репозитории как локальный `.aar` в `core/hardware/libs/`.
