# Glyph Charging Meter

Приложение для телефонов Nothing: во время зарядки показывает уровень заряда на Glyph-интерфейсе и проигрывает анимацию при подключении питания.

## Зачем это нужно

На Phone (3a) и Phone (3a) Pro встроенного индикатора заряда (Charging meter) нет: Nothing не перенесла эту функцию с Phone (1) и (2). Приложение возвращает её.

## Чем отличается от аналогов

Штатный `displayProgress` заполняет шкалу шагами по сегменту: на длинной зоне это 20 ступеней, то есть 5% заряда на ступень, и шкала заметно дёргается. Здесь яркость задаётся для каждого сегмента отдельно: целые сегменты горят на полной яркости, а следующий светится частично, пропорционально дробному остатку. Например, 63% на зоне из 20 сегментов это 12 сегментов на полной яркости и 13-й на 60%. Дополнительно шкала плавно переходит к новому значению при изменении заряда. Если недокументированная перегрузка SDK исчезнет в обновлении, приложение на время сеанса перейдёт на ступенчатый режим и покажет на главном экране предупреждение о сниженной плавности. Если Glyph совсем перестал отвечать (отказ в доступе, обрыв связи, ошибка отрисовки), главный экран показывает карточку с причиной и кнопкой «Проверить снова»; после потери связи сервис сам пробует переподключиться ограниченное число раз.

Режимы индикатора: постоянный (шкала горит всю зарядку) и по событию (анимация при подключении, затем шкала держится заданное время и гаснет). В приложении есть превью пресетов: кнопка проигрывает анимацию и на экране телефона, и на самом Glyph (на Glyph — когда приложение включено и имеет доступ к Glyph), настройки яркости и длительности показа, а также гашение Glyph, когда телефон лежит экраном вверх.

## Поддерживаемые устройства

| Устройство | Статус |
|---|---|
| Nothing Phone (3a), Phone (3a) Pro | Целевые устройства, раскладка добавлена. Проверка на железе ещё не проводилась |
| Остальные модели Nothing | Не поддерживаются сейчас; архитектура допускает добавление одной записью в таблицу раскладок |

Работа на живом телефоне пока не подтверждена: проект проверен только автоматическими тестами. Поведение SDK на Nothing OS 3.x без debug-режима и точная семантика отдельных вызовов подлежат проверке на устройстве.

## Установка

Скачайте `glyph-meter-<версия>.apk` со страницы [Releases](https://github.com/swrneko/ngcm/releases) и установите его на телефон. Можно открыть файл прямо на телефоне, разрешив установку из этого источника, или поставить с компьютера:

```bash
adb install glyph-meter-0.1.0.apk
```

Релизы помечены как предварительные, пока приложение не проверено на живом телефоне. Обновления подписываются одним ключом, поэтому новая версия ставится поверх старой без удаления.

**Nothing OS 4.0 и новее (Android 16).** Ничего настраивать не нужно: ограничение на доступ к Glyph снято.

**Более старые версии.** Нужен включённый Glyph Debug Mode, который система сбрасывает каждые 48 часов. Чтобы приложение включало его само, один раз выдайте ему разрешение командой с компьютера (телефон подключён по USB, включена отладка по USB):

```bash
adb shell pm grant com.swrneko.glyphmeter android.permission.WRITE_SECURE_SETTINGS
```

После этого приложение включает отладочный режим само, к компьютеру возвращаться не нужно. Механизм такой: перед каждым подключением к Glyph, при каждом подключении питания и после загрузки телефона приложение заново записывает флаг, так что 48-часовой сброс системы не успевает помешать. Условие: сервис должен работать (переключатель включён). Эту же команду показывает экран онбординга.

**Альтернатива без компьютера: Shizuku.** Shizuku запускается один раз через беспроводную отладку прямо на телефоне, и приложение записывает флаг через него. В онбординге есть кнопка запроса разрешения у Shizuku, провайдер Shizuku объявлен в манифесте. Минус: после перезагрузки телефона Shizuku нужно запускать заново. Этот путь реализован, но на живом телефоне не проверялся.

## Сборка из исходников

Нужны JDK 17 и Android SDK с платформой `android-37` (путь к SDK в `local.properties`, строка `sdk.dir=...`).

```bash
git clone https://github.com/swrneko/ngcm.git
cd ngcm
./gradlew assembleDebug    # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew test             # юнит-тесты
```

Релизная сборка `./gradlew assembleRelease` подписывается, только если в корне лежит `keystore.properties` с ключом. Без него получится неподписанный APK. Ключ есть только у автора, поэтому собранный самостоятельно APK не встанет поверх версии из Releases: сначала удалите её.

Glyph SDK лежит в репозитории как локальный `.aar` в `core/hardware/libs/`.
